## 发布机制

GitHub 一个仓库只有一个 Pages 站点，所以采用“一次发布，两套目录”：

```text
站点根目录 /chem-gemini/       ← P0 课堂展示版
├── index.html、assets/        ← 展示版固定提交，按 Pages 静态模式构建
├── release-manifest.json     ← 两版提交和两套文件的 SHA-256
└── p1/                       ← 独立 P1
    ├── index.html
    └── assets/
```

`.github/workflows/p1-pages.yml` 只在 `p1-release` 推送或手动运行时发布。它执行：

1. 安装依赖，校验化学数据，运行单元测试。
2. 构建并测试本机 P1，全部 AI 请求使用模拟响应。
3. `npm run build:pages` 构建静态 P1，资源 base 为 `/chem-gemini/p1/`。
4. `npm run test:pages` 验证静态版标记、密钥边界、离线教学链路及自备 API。
5. 单独检出 P0 标签，先核对完整提交与 `P0_COMMIT` 一致，再在 `.pages-p0` 校验数据及单元测试，用其自己的 `npm run build:pages && npm run test:pages` 验证根路径静态版。不要用普通本机版构建发布。
6. `npm run assemble:pages` 把 P0 原样放在根目录，把 P1 放入 `p1/`；核对两版的 DOM 标记、入口所引用 JS/CSS 的实际路径与存在性、复制前后全部文件指纹，拒绝互相覆盖。
7. `npm run test:pair` 在同一站点、同一浏览器标签页往返两个正式路径，验证样式/脚本来源和配置命名空间。通过后才上传双版构建产物并部署。

旧的单版本 `Deploy to GitHub Pages` 工作流在新版成功部署后停用，避免它单独重发 P0 时删除 P1。后续更新 P1 请推送 `p1-release`，不要运行旧发布工作流。Pages 的 `github-pages` 环境仅需额外允许 `p1-release`，不必把环境部署权限开放给任意分支。

### 展示版更新与回退

- 更新 P0：先在 `p0-showcase` 验证并推送新标签，再在本发布工作流一起更新 `P0_TAG` 和 `P0_COMMIT`。直接推送展示分支不会改动线上网站。未来正常发布 P1 时继续保留已固定的 P0 展示版。
- 回退第 4 步五栏默认折叠的改动：在 `.github/workflows/p1-pages.yml` 将 `P0_TAG` 恢复为 `v2.1.0-p0`、`P0_COMMIT` 恢复为 `03eb86a18d27e28fbb1164b286fd75f61696109e`，提交后通过 `p1-release` 重新部署。该标签保留，已在独立目录重建并比对旧产物；不用改动 P1 教学源码、移动标签或强推。部署后核对 [发布清单](https://warrrm.github.io/chem-gemini/release-manifest.json) 的 P0 标签和 P1 资源指纹。
- 如需同时撤销物质卡片的用途、制法与方程式增强，仍可将两项固定值设为 `v2.0.1-p0` 与 `d27bd8de07e0d2a6cfa1393d7e15b2324cd0ebbd`。
- 如要退回最初的离线 P0，旧 `7915a15` 不支持 `build:pages`，不能只改 SHA。以 `v1.3.0-p1` 为参考，恢复当时的 `.github/workflows/p1-pages.yml`、`scripts/assemble-pages.ts` 和 `tests/pages-assembly.test.ts`，保留届时的 P1 应用源码，重新验证双版本再发布；不要用旧的单站部署，也不需要强推或移动标签。

## 密钥与线上识图限制

- 本机 `.env.local` 不提交到 GitHub，也不进入 Pages 构建产物。
- 本机 `npm run dev` / 普通 `npm run preview` 仍可通过 Node 网关使用默认 DeepSeek Key。
- GitHub Pages 是静态托管，不能执行 Node 网关。静态版默认使用空的自备 Key，明确显示说明，并禁用不存在的内置密钥连接。
- 线上可直接体验内置样例、本地搜索和完整化学学习流程；真实在线识图需用户明确填写自备 API Key，且接口必须允许浏览器 CORS。此处不承诺官方接口一定允许浏览器跨域。
- 如需学生无 Key 直接在线识图，必须另外部署带鉴权、配额、限流和 TLS 的服务端；不要把共享默认 Key 硬编码到前端。
- 更换接口会清除旧 Key、撤销图片授权。自备 Key 仅保存在当前标签页 sessionStorage；两版的配置键与图片授权互不继承或清除，图片发送前仍需同意。

## P1 1.2.0 教学改进

- 步骤三按顺序开放：元素质量比 → 第一次答错后的元素与化合价 → 再次答错后的微观示意图；空白提交不计错，不再有任意提前展开提示的按钮。
- 前后导航保留线索进度，换物质、重置学习时清空；正确作答仍立即解锁后续步骤。
- 单质不伪造跨元素质量比，化合价为 0；过氧化氢、甲烷、四氧化三铁等采用专门的正确价态规则。
- 步骤六在原有题型之外附加一道可换的计算题。49 个物质共 178 个通用版模板，答案依据化学式、相对原子质量与配平反应计算，不消耗 AI 额度。
- 计算题区分相对分子质量、相对式量、相对原子质量，校验数值与单位；计算过程不会在提交前显示，支持教师延迟揭晓。
- 微观图不再把原子团的整体电荷误标在单个中心原子或羟基氧原子上。原知识库仍需教师审校，示意图不能代替完整结构模型。

## P1 1.2.1 问题修复

### 答对后开放全部线索

之前线索只按错误次数计算，导致首次答对后返回步骤三仍只有第一条线索。现将「本关已校验通过」也作为开放条件：首次答对、纠错后答对均直接开放三条线索，来回导航不重新锁住；换物质或重置时仍从第一条开始。保留原先答对后自动进入知识卡片的行为，回到步骤三可查看完整线索。

### 实验题显示与换题

原有实验题只有 7 道，旧查询只接受当前物质的直接题或单向主要成分回退，导致部分物质无题、另一些只有一道，点击换题仍是原题。

修复后在同教材范围内依次排列本物质题、同成分 / 溶质题、相关反应题及综合题，明确展示当前题目的主题和关联范围。没有专属题时使用有标注的综合题，不声称补齐了每种物质的专属实验库。题库内容仍是原有 7 道，不调用 AI 临时编造实验。

实验题标签可进入；异常空池显示说明而不是空白。当前题号可见，连续换题先遍历再循环，清空上题作答与揭晓状态；少于两题时禁用无效换题。切换教材或物质时重建练习面板，避免旧题旧答案残留。选择题、实验题、附加计算题的作答相互独立；教师延迟揭晓仍有效。

### 回归验证

- 单元测试：8 个文件、84 条。
- 本机浏览器验收：33 个场景。
- 静态浏览器验收：20 个场景，包含首次答对和纠错后答对、实验题显示 / 连续换题 / 全池循环、无专属题回退、教师延迟揭晓、教材与物质切换重置，以及手机无横向溢出。
- 数据校验新增实验题字段完整性、题目 ID 唯一性、全部物质和教材范围可换题检查。
- 本轮未改变 AI 密钥配置，不使用真实付费模型；P0 仍从固定源码独立构建。

## P1 1.3.0 微观图与练习区优化

- 把原来仅用原子数自动猜连线的绘图改为 `src/data/microStructures.ts` 的 49 个显式本地结构。过氧化氢画成非平面扭转的 H—O—O—H，每个氧只连一个氢；二氧化碳用直线形，水用折线形，甲烷用带透视的四面体。纯硫酸和碳酸的氢连在氧上，不画硫氢键或碳氢键。
- 氢氧根、碳酸根、硫酸根等分别绘制，括号右上角标整个离子的电荷；固态离子化合物显示个数比而非晶胞。稀盐酸画水合氢、氯离子和溶剂水，不把溶液画成未电离的氯化氢。硫酸铜溶液标明水合铜离子与硫酸根，水合层省略；石灰石只表示其主要成分。图为教学示意，不代表真实键长、浓度、晶型，也不能凭照片判定微观结构。
- 全部演示样例及 49 种物质的模拟识图浏览器验收均覆盖；另核对组成、离子电荷平衡、坐标与连接、图形是否裁剪。无标签仍须确认物质，仪器及教材范围外对象不生成微观图。
- 三种练习题在同级标签下显示，换题只换当前题型，保留各自作答和教师延迟解析方式。通用题尾提供学科网官网 `https://www.zxxk.com/` 作为拓展链接，不冒充题目来源。

微观模型核对参考：[NIST 过氧化氢实验数据](https://cccbdb.nist.gov/exp2x.asp?casno=7722841&charge=0)、[OpenStax 分子结构](https://openstax.org/books/chemistry-2e/pages/7-6-molecular-structure-and-polarity)、[酸在水中的电离](https://openstax.org/books/organic-chemistry/pages/2-7-acids-and-bases-the-bronsted-lowry-definition)及[固体结构](https://openstax.org/books/chemistry-2e/pages/10-5-the-solid-state-of-matter)。代码与示意图已核对，不代表题库已经过教师人工审校。
