# 化学识物小课堂 (`chem-gemini`)

> **从一张照片，认识一种物质** —— 面向初中学生的互动式化学学习与教师课堂演示网站。

## 项目简介

「化学识物小课堂」围绕初中化学核心学习目标设计了一套**六步闯关式互动学习流程**。学生在辨认物质名称后，不会直接看到剧透的化学式和性质，而是先观察**微观粒子构成示意图**或**元素质量比**，亲手推导并输入正确的化学式，校验通过后方可解锁物质知识卡片、初中化学反应方程式与随堂练习。

## 核心六步学习流程

1. **图片上传与预览**：支持调用摄像头拍照（`getUserMedia`）和本地图片上传（权限拒绝时自动降级引导本地上传），并提供 6 组覆盖 5 大教学与验收场景的内置演示样例。
2. **候选物质与名称确认（防剧透）**：仅展示候选物质名称，不提前泄露化学式或性质；支持多物体图片点选（区分实验仪器与化学物质）、无标签未知物质安全提示、教材范围外物质拦截以及本地名称/俗称模糊搜索。
3. **推导并书写化学式（解锁关卡）**：提供可切换的**微观构成示意图（SVG）**与**最简整数元素质量比**线索；混合物与溶液明确提示书写其**主要成分 / 溶质**的化学式；输入框支持数字自动转下标实时预览、快捷角标按钮、5 类分级错误引导与 3 级渐进提示。
4. **物质知识卡片**：醒目标注“以下内容按你选择的物质展示”，区分“物体（混合物/溶液）”与“主要成分/溶质”，系统呈现化学式、俗称、物质类别、物理性质、化学性质、常见用途与核心概念辨析。
5. **相关反应方程式**：从结构化反应库检索该物质（或其主要成分）**作为反应物**与**作为生成物**的初中化学反应，自动排版系数、反应条件与气体/沉淀符号（`↑` / `↓`），附带实验现象与核心知识点。
6. **随堂练习与反馈**：提供**单项选择题**（默认）与**实验探究题**两种题型，支持“换一道题”且不重复上一题；答案与逐项解析在提交前严格隐藏，提交后展开核对与评分要点。

## 数据与审校说明

- **审校状态**：当前内置的 45 种物质（含 29 种核心物质/混合物/溶液及 16 种反应关联延伸物质）、36 条化学反应方程式与 65 道随堂练习题均标注为 **「AI 整理，尚未经教师审校」**，出处统一标注为 **「通用初中化学基础（知识库自编，未对应具体页码）」**，不虚构任何教材章节与页码。
- **教材版本配置**：支持切换「通用版」「人教版」「沪教版」「鲁教版」标签筛选，页面常驻提示「版本适配仅供参考，以所用教材为准」。
- **隐私保护**：用户拍摄或上传的图片仅在当前浏览器会话内存中使用（`URL.createObjectURL`），不写入持久化存储，不上传至任何服务器。

## 本地运行与测试

```bash
# 1. 安装依赖
npm install

# 2. 校验结构化化学数据（原子守恒、气体/沉淀符号、质量比、安全性）
npm run validate:data

# 3. 运行单元测试
npm test

# 4. 启动本地开发服务器
npm run dev

# 5. 构建生产版本并运行端到端验收测试
npm run build
npm run test:e2e
```
